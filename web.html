Desarrollo Web: HTML, CSS y JS

Fundamentos esenciales para crear sitios web modernos, desde la estructura hasta la interactividad.

HTML: Estructura semántica, formularios, tablas y etiquetas esenciales.
CSS: Selectores, Flexbox, Grid, responsive design y animaciones.
JavaScript: Manipulación del DOM, eventos, funciones y consumo de APIs.

1. Trilogía Web: Estructura, Estilo e Interacción

Una página web se construye combinando tres tecnologías principales que trabajan juntas de forma coordinada. Podemos entenderlas fácilmente usando la analogía del cuerpo humano o de un edificio:

HTML5

El Esqueleto: Define la estructura y el contenido de la página mediante etiquetas (textos, imágenes, enlaces, formularios).

CSS3

La Apariencia: Aporta diseño, colores, tipografía, disposición gráfica y adaptabilidad a dispositivos móviles (Responsive Design).

JavaScript

El Sistema Nervioso: Añade interactividad, lógica, comportamiento dinámico y respuesta inmediata a las acciones del usuario.

2. HTML5: HyperText Markup Language

HTML utiliza etiquetas para delimitar los diferentes elementos del documento. Casi todas las etiquetas constan de una apertura (<etiqueta>) y un cierre (</etiqueta>).

Estructura básica de un documento HTML5

index.html HTML5
<!DOCTYPE html> <html lang="es"> <head> <meta charset="UTF-8"> <title>Mi Primera Página Web</title> </head> <body> <h1>¡Hola Mundo!</h1> <p>Este es un párrafo de texto explicativo.</p> <a href="https://google.com">Visitar Google</a> </body> </html>

Principales Etiquetas Semánticas

  • <header>: Encabezado principal de la web o de una sección.
  • <nav>: Contenedor para enlaces de navegación.
  • <main>: Contenido principal e indispensable del documento.
  • <section> y <article>: Bloques temáticos o artículos autónomos.
  • <footer>: Pie de página con derechos, enlaces o contacto.

3. CSS3: Cascading Style Sheets

CSS describe cómo se deben mostrar los elementos HTML en la pantalla. Funciona seleccionando elementos e indicando reglas de diseño formadas por propiedades y valores.

styles.css CSS3
/* Selector que aplica estilos al contenedor */ .tarjeta { background-color: #ffffff; border-radius: 12px; padding: 20px; box-shadow: 0 4px 10px rgba(0,0,0,0.1); transition: all 0.3s ease; } .tarjeta:hover { transform: translateY(-5px); }

4. JavaScript: Dinamismo y Lógica

JavaScript permite manipular el documento HTML en tiempo real mediante el DOM (Document Object Model), respondiendo a los eventos del usuario como clics, desplazamientos o ingresos de texto.
