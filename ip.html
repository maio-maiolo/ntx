MÓDULO - DIRECCIONAMIENTO IP

Direccionamiento IP: IPv4 e IPv6

Comprende el funcionamiento del direccionamiento IP y la transición hacia el nuevo protocolo.

IPv4: Estructura de 32 bits, clases, máscara de subred y NAT.
IPv6: Estructura de 128 bits, notación hexadecimal y ventajas.
Subnetting: Cálculo de redes, hosts y planificación de direccionamiento.

1. ¿Qué es una Dirección IP?

Una Dirección IP (Internet Protocol) es una etiqueta numérica lógica y jerárquica que identifica de manera única a una interfaz de red de un dispositivo (computadora, smartphone, servidor, impresora) dentro de una red que utilice el protocolo IP.

Identificación

Permite saber quién es cada dispositivo dentro de la red local o en Internet mundial.

Localización

Proporciona la ruta para saber dónde se encuentra ubicado el equipo en la topología de red.

Ruteo de Paquetes

Los routers utilizan la IP de destino para reenviar los paquetes de datos por el mejor camino.

Nivel de Red

Opera en la Capa 3 (Red) del modelo OSI y en la capa de Internet del modelo TCP/IP.

Analogía: Una dirección IP funciona igual que la dirección postal de una casa. El nombre de calle y número permite que el cartero (Router) entregue la carta (Paquete de Datos) en la puerta exacta.

2. Protocolo IPv4 (Versión 4)

IPv4 es la cuarta versión del Protocolo de Internet y el estándar dominante desde la creación de ARPANET. Utiliza direcciones de 32 bits, lo que permite un espacio total de aproximadamente 4.294.967.296 (4,3 mil millones) de direcciones únicas.

Formato Decimal Punteado

Los 32 bits se dividen en 4 octetos (bloques de 8 bits) separados por puntos. Cada octeto se convierte a número decimal (de 0 a 255).

192 . 168 . 1 . 50
Octeto 1 (8 bits) Octeto 2 (8 bits) Octeto 3 (8 bits) Octeto 4 (8 bits)

En binario: 11000000.10101000.00000001.00110010

Partes de una Dirección IP: Red y Host

Porción de Red (ID de Red)

Identifica el segmento de red específico en el que se encuentra el dispositivo. Todos los equipos en la misma red comparten la misma porción de red.

Porción de Host (ID de Host)

Identifica al dispositivo concreto e individual dentro de esa red específica. Debe ser único dentro de esa subnet.

Clases de Direcciones IPv4 (Clasificación Clásica - Classful)

Clase Rango del 1° Octeto Máscara por Defecto Uso Principal
Clase A 1.0.0.0 a 127.255.255.255 255.0.0.0 (/8) Redes muy grandes (Gobiernos, multinacionales)
Clase B 128.0.0.0 a 191.255.255.255 255.255.0.0 (/16) Redes medianas (Universidades, empresas)
Clase C 192.0.0.0 a 223.255.255.255 255.255.255.0 (/24) Redes pequeñas (Hogares, pymes)
Clase D 224.0.0.0 a 239.255.255.255 N/A Multicast (Transmisión a grupos)
Clase E 240.0.0.0 a 255.255.255.255 N/A Uso experimental y de investigación

Direcciones IP Privadas vs. Públicas

IP Privada

Utilizadas dentro de redes locales (LAN). No son ruteables en Internet. Definidas por la RFC 1918:

  • 10.0.0.0 – 10.255.255.255 (Clase A)
  • 172.16.0.0 – 172.31.255.255 (Clase B)
  • 192.168.0.0 – 192.168.255.255 (Clase C)

IP Pública

Asignadas por el proveedor de Internet (ISP). Únicas en todo el mundo y ruteables en Internet para acceder a servidores y páginas web.

3. Protocolo IPv6 (Versión 6)

Ante el agotamiento de direcciones IPv4 provocado por el crecimiento de Internet y dispositivos móviles/IoT, se diseñó IPv6. Utiliza direcciones de 128 bits, ofreciendo un número astronómico de direcciones (aproximadamente 3,4 × 1038 direcciones).

Formato Hexadecimal

Se escribe representada en 8 grupos de 4 dígitos hexadecimales (hextetos) separados por dos puntos (:).

2001 : 0db8 : 85a3 : 0000 : 0000 : 8a2e : 0370 : 7334

Reglas de Abreviación de IPv6

Para simplificar la escritura de direcciones IPv6 largas, se aplican dos reglas estrictas:

1. Omisión de ceros a la izquierda

En cualquier hexteto se pueden eliminar los ceros iniciales. Ej: 0db8 se convierte en db8, y 0000 se convierte en 0.

2. Compresión de ceros consecutivos (::)

Una secuencia contigua de uno o más hextetos compuestos por ceros se puede reemplazar por un doble dos puntos (::). ¡Solo se puede usar UNA VEZ por dirección!

Ejemplo de Abreviación:
Original: 2001:0db8:0000:0000:0000:0000:1428:57ab
Aplicando omisión y compresión: 2001:db8::1428:57ab

4. Comparativa IPv4 vs IPv6

Característica IPv4 IPv6
Tamaño de Dirección 32 bits (4 octetos) 128 bits (8 hextetos)
Formato de Representación Decimal punteado (ej. 192.168.1.1) Hexadecimal (ej. 2001:db8::1)
Cantidad de Direcciones ~4,3 mil millones ~3,4 × 1038 (Prácticamente ilimitadas)
Configuración de IP Manual o por DHCP Autoconfiguración (SLAAC) y DHCPv6
Seguridad Integrada Opcional (IPsec) Nativa en el protocolo
