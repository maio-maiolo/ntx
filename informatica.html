¿Qué es una computadora?

Una computadora es un sistema informático programable capaz de recibir, almacenar y procesar datos para convertirlos en información útil. A diferencia de otras máquinas, no realiza una sola tarea fija, sino que puede ejecutar una enorme variedad de programas según lo que el usuario necesite.

Para que este proceso funcione, el sistema opera a través de un ciclo continuo que abarca cuatro etapas fundamentales:

1. Entrada de datos

Captura de información mediante periféricos (teclado, mouse, cámara, micrófono).

2. Almacenamiento

Datos e instrucciones guardados temporal o permanentemente en memoria principal y discos.

3. Procesamiento

El microprocesador ejecuta instrucciones del software para transformar datos crudos.

4. Salida de información

Muestra de resultados mediante pantallas, parlantes o impresoras.

Ejemplo cotidiano: Cuando grabas un audio de WhatsApp (Entrada), el celular lo guarda en su memoria (Almacenamiento), la aplicación lo comprime y codifica (Procesamiento) y finalmente se envía y reproduce para que otra persona lo escuche (Salida).

Elementos de una computadora digital

Una computadora no es una única máquina aislada, sino un sistema integrado compuesto por diferentes componentes que trabajan en conjunto, divididos tradicionalmente en dos grandes grupos:

Hardware

Componentes físicos y tangibles del sistema, todo lo que podemos ver y tocar (teclado, monitor, memoria RAM, microprocesador). Es el cuerpo de la computadora.

Software

Parte lógica e intangible; conjunto de instrucciones, datos y programas que indican al hardware qué hacer (sistemas operativos como Windows 11, aplicaciones de oficina).

Componentes del Hardware

Dentro de los elementos que componen el hardware de una computadora personal (PC), podemos enumerar los siguientes:

Microprocesador (CPU)

Considerado el "cerebro" de la computadora, se encarga de administrar el sistema y ejecutar instrucciones. Su velocidad se mide en Gigahercios (GHz). Compuesto por la Unidad de Control (UC) y la Unidad Aritmético-Lógica (ALU).

Memoria Principal

Incluye la Memoria RAM (almacenamiento temporal y volátil para programas en ejecución) y la Memoria ROM (circuito no volátil de solo lectura que contiene la información básica de arranque o BIOS).

Disco Duro / SSD

Dispositivos de almacenamiento secundario y permanente. Los discos rígidos tradicionales (HDD) utilizan componentes mecánicos, mientras que las unidades de estado sólido (SSD) emplean memoria flash, ofreciendo una velocidad de lectura y escritura muy superior.

Tarjeta Madre (Placa Base)

Es la placa de circuito impreso principal que sirve como columna vertebral de la computadora. Conecta e interconecta todos los componentes entre sí (CPU, memoria, tarjetas de expansión y periféricos) permitiendo la comunicación entre ellos.

Tarjeta Gráfica (GPU)

Procesador o tarjeta dedicada exclusivamente al procesamiento de datos de video e imágenes. Se encarga de acelerar la renderización de gráficos en 2D y 3D, siendo fundamental para videojuegos, diseño gráfico y edición.

Fuente de Alimentación

Dispositivo que se encarga de transformar la corriente alterna (AC) de la red eléctrica en corriente continua (DC) de bajo voltaje, distribuyendo la energía eléctrica necesaria y estable a cada uno de los componentes internos del equipo.

Placa de Red

Dispositivo (Ethernet o Wi-Fi) que permite a la computadora conectarse a una red de área local (LAN) o a internet. Se encarga de preparar, enviar y controlar los paquetes de datos que se transmiten entre los equipos de la red.

Placa de Sonido

Dispositivo encargado de procesar las señales de audio. Convierte las señales digitales de la computadora en sonido analógico audible para altavoces y auriculares, y viceversa, permitiendo también la entrada de audio mediante micrófonos.

Cooler / Ventilador

Sistema de ventilación encargado de disipar el calor generado por los componentes internos de alto rendimiento, expulsando el aire caliente hacia el exterior para mantener temperaturas óptimas de funcionamiento.

Componentes de Software

El software es todo componente intangible (y no físico) que forma parte de dispositivos, como computadoras, teléfonos móviles o tabletas, y que permite su funcionamiento. Está compuesto por un conjunto de aplicaciones y programas diseñados para cumplir diversas funciones dentro de un sistema, trabajando con la información del usuario y los datos procesados.

Ejemplos de software son los procesadores de texto, como Microsoft Word; sistemas operativos, como Windows; o aplicaciones, como Instagram o WhatsApp. Los programas que forman parte del software le indican al hardware (parte física de un dispositivo), por medio de instrucciones, los pasos a seguir.

Tipos de software

Los software se clasifican según su función en tres grandes categorías:

Software de sistema

Programas que dan al usuario la capacidad de relacionarse con el sistema, para ejercer control sobre el hardware. El software de sistema también se ofrece como soporte para otros programas.

Ejemplos: Sistemas operativos o servidores (Windows, Apple, Android, Linux).

Software de programación

Programas diseñados como herramientas que le permiten a un programador desarrollar programas informáticos. Se valen de técnicas y un lenguaje de programación específico.

Ejemplos: Compiladores, editores multimedia, herramientas como Java, HTML5, MySQL, SQL Server, jQuery.

Software de aplicación

Programas diseñados para realizar una o más tareas específicas a la vez, pudiendo ser automáticos o asistidos.

Ejemplos: Videojuegos, reproductores multimedia, Skype, Word, Adobe Illustrator.

Ejemplos de software

Existen muchos ejemplos de software, que se clasifican según su función en:

  • Software de edición de imágenes: Adobe Photoshop, Paintshop, GIMP.
  • Software de procesador de texto: Microsoft Word, WordPad, Block de notas.
  • Software de audio: Adobe Audition, Ableton, Pro Tools.
  • Software de comunicación: Facebook, Skype, Zoom.
  • Software de diseño y arquitectura: AutoCAD, Adobe Illustrator, Revit.
  • Software de contabilidad: Loggro, Xero, Nubox.
  • Software de sistema operativo: Linux, MacOS, Windows.
  • Software de protección contra virus: AVG Antivirus, McAfee, Panda.
  • Software de programación: Microsoft Visual Studio, Xcode, Lazarus.

Diferencia entre software y hardware

Todo dispositivo está formado tanto por la parte intangible, el software, como por la parte tangible, el hardware. El hardware es el conjunto de elementos materiales que forman parte de un dispositivo electrónico (por ejemplo, monitor, teclado, ratón, etc.).

Tanto el software como el hardware resultan piezas claves para la correcta ejecución de un ordenador o aparato móvil. Los usuarios no podrían ejecutar un software sin la presencia de un hardware y, a su vez, el hardware resulta inútil sin un software. Ambos son opuestos, pero complementarios, por lo que trabajan en conjunto.

Cada dispositivo está compuesto por diferentes piezas de hardware que pueden ser electrónicas, eléctricas o mecánicas y que cumplen una función específica (como una memoria de almacenamiento o una placa de video). Existe el hardware principal, indispensable para el correcto funcionamiento del aparato, y el hardware complementario, formado por accesorios con funcionalidades específicas.

¿Qué es el software libre?

El software libre es un software en el que los usuarios pueden acceder a su código fuente para estudiarlo, copiarlo o modificarlo. El término y las ideas que engloba fueron introducidas en 1984 por el programador estadounidense Richard Matthew Stallman, quien creó la Free Software Foundation con el fin de extender este tipo de software y rescatar la idea de libertad del usuario.

Un software se considera libre cuando:

  • Se lo puede utilizar con cualquier propósito.
  • Se lo puede estudiar, conocer su funcionamiento y modificar en caso de creerlo necesario.
  • Se pueden distribuir copias.
  • Puede ser mejorado por cualquier usuario.

Dispositivos de la Computadora

1. ¿Qué es un periférico y cómo se clasifican?

Se llama periférico a todo el hardware que se halla conectado externamente a la placa madre o principal de una computadora (ya sea dentro o fuera del gabinete). Se clasifican en cuatro grandes grupos según la dirección en la que viaja la información:

Almacenamiento

Permiten la entrada y salida de información, guardándola de forma permanente o semipermanente. (Ej.: discos rígidos, pendrives, tarjetas de memoria).

Entrada

Solo ingresan información desde el exterior hacia la PC. (Ej.: teclado, mouse, escáner, micrófono).

Salida

Permiten extraer o visualizar la información procesada por la computadora. (Ej.: parlantes, auriculares, impresora).

Mixtos (E/S)

Transportan información en ambos sentidos (hacia y desde la PC). (Ej.: pantallas táctiles, gamepads con vibración).

Periféricos de Almacenamiento Masivo

Son dispositivos encargados de guardar toda la información de la computadora de forma permanente, incluso cuando esta se apaga. Se dividen principalmente en tres tecnologías:

Discos (Magnéticos y Estado Sólido)

Discos Rígidos Magnéticos (HDD): Compuestos por discos de aluminio apilados en un eje giratorio con material magnético y cabezales de lectura/escritura. Capacidades desde 500 GB hasta varios TB.

Discos de Estado Sólido (SSD): Sin partes mecánicas; usan memoria flash no volátil. Son resistentes a golpes, silenciosos, de bajo consumo y muy rápidos.

Discos Ópticos y Flash

Discos Ópticos: Leídos mediante rayo láser. Incluyen CD (700-800 MB), DVD (4.7 GB a 17 GB) y Blu-ray (25 GB por capa para alta definición).

Memoria Flash: Pendrives y tarjetas de memoria para celulares y cámaras. Seguros, pequeños y transportables.

Periféricos de Entrada

Permiten al usuario interactuar con la PC introduciendo datos y órdenes:

Teclado

Posee hasta 147 teclas divididas en cuatro bloques:

  • Funciones: F1 a F12.
  • Numéricas: Del 0 al 9 y operaciones básicas.
  • Alfanuméricas: Letras, números y símbolos.
  • Control: Flechas, RePág, AvPág, Suprimir, Inicio, Fin.

Mouse y otros dispositivos

Mouse (Ratón): Apunta en pantalla mediante sensor óptico; posee dos botones y rueda de desplazamiento (scroll).

Otros: Lector de códigos de barras, lápiz óptico, lector de tarjetas de crédito, cámaras digitales, webcams y micrófonos.

Componentes Internos Esenciales

Bus de Datos y Placa Madre

Bus de Datos: Líneas conductoras para la comunicación interna entre microprocesador, RAM, discos y puertos (de datos, direcciones y control).
Placa Madre (Motherboard): Tarjeta de circuito impreso principal donde se conecta todo el hardware.

Tarjetas de Expansión y Puertos

Tarjetas de Expansión: Circuitos añadidos (como la GPU dedicada). Incluye pila interna para fecha y hora de la BIOS.
Puertos y Conectores: USB, HDMI, VGA y Jacks de audio.

3. Proceso Computacional y Sistema Informático

Diferenciar sistema informático vs proceso computacional.

Sistema Informático = Hardware + Software + Orgware + Recurso Humano

No es solo la PC. Es el conjunto: máquinas (hardware), programas (software), procedimientos (orgware) y personas (humanware). Si falta uno, no funciona.

Proceso Computacional: Entrada → Procesamiento → Salida (EVS)

1. ENTRADA
Teclado, mouse, micrófono, escáner. Captura datos crudos. Ej: tipeás "25"
2. PROCESAMIENTO
CPU (ALU + UC) + RAM. Transforma dato en información. Ej: calcula 25°C = calor
3. SALIDA
Monitor, impresora, parlantes. Muestra resultado. Ej: "Hace 25°C, hace calor"

Características de un computador: Almacenamiento y Velocidad

Almacenamiento: Capacidad de guardar datos. Se mide en bytes (KB, MB, GB, TB... hasta YB). Incluye RAM (volátil, rápida) y almacenamiento masivo (HDD, SSD, no volátil).
Velocidad de procesamiento: Se mide en Hz (GHz). Depende de CPU (núcleos, caché), RAM y bus de datos. Más GHz y más núcleos = más instrucciones por segundo.
Tips: ¿Qué es ALU y UC? ALU = Unidad Aritmético-Lógica (calcula). UC = Unidad de Control (dirige). Ambas están dentro de la CPU. ¿Qué es sistema binario? Solo 0 y 1, base 2. ¿Digitalización? Convertir analógico (voz, foto) en 0 y 1 para que la PC lo entienda.

B. Procesadores de Texto (consideraciones generales)

¿Para qué sirve?

Crear, editar y dar formato a documentos de texto. Ej: Word, Writer (LibreOffice), Google Docs.

  • Formato: fuente, tamaño, negrita, alineación
  • Insertar: imágenes, tablas, encabezado/pie
  • Revisión: ortografía, comentarios, control de cambios
  • Guardar como: .docx, .pdf, .odt
Concepto de programa vs procesador:

Programa = secuencia de instrucciones que hace una tarea (ej: "calcular promedio"). Procesador de texto = tipo de programa de aplicación que sirve para escribir. No confundir.

Error común: Pensar que Word es sistema operativo. No, Word es aplicación que corre SOBRE el Sistema Operativo.

C. Planillas Electrónicas de Cálculo (consideraciones generales)

¿Para qué sirve una planilla? (Excel, Calc, Sheets)

Organizar datos en filas y columnas (celdas) y hacer cálculos automáticos. Es la base de la administración y la contabilidad digital.

Conceptos básicos:
  • Celda: cruce fila (1,2,3) + columna (A,B,C) → A1, B2
  • Rango: conjunto de celdas → A1:C10
  • Fórmula: empieza con = → =SUMA(A1:A10)
  • Función: operación predefinida (SUMA, PROMEDIO, SI)
  • Gráfico: visualiza datos (barras, torta, líneas)
Ejemplos:
  • =A1+B1 → suma
  • =PROMEDIO(B2:B20) → promedio de notas
  • =SI(C2>=6;"Aprobado";"Desaprobado")
  • Formato: moneda, fecha, porcentaje
  • Ordenar y filtrar datos

Diferencia: procesador de texto = texto corrido. Planilla = números y cálculos.

Tips: Administración Sistema Operativo = gestionar archivos, usuarios y mantenimiento. Procesador de texto = crear documentos con formato (.docx/.pdf). Planilla = celdas, fórmulas con = y funciones (SUMA, PROMEDIO).

Unidades de Almacenamiento y Medidas Digitales

En el mundo digital, los datos se almacenan, procesan y transfieren mediante un sistema binario basado en bits y bytes. Comprender la memoria y las unidades de almacenamiento es fundamental para entender cómo las computadoras gestionan la información y realizan tareas de manera eficiente.

Para medir el tamaño de los datos y la capacidad de los dispositivos digitales, utilizamos una escala de unidades que va desde la mínima expresión hasta escalas masivas:

Bit / Nibble / Byte

El Bit (0 o 1) es la unidad mínima. 4 bits forman un Nibble y 8 bits forman un Byte, capaz de almacenar un carácter (ej. "A" o "7").

KB / MB

Kilobyte (KB): Equivalente a 1.024 bytes, para archivos de texto o gráficos pequeños.
Megabyte (MB): Equivalente a 1.024 KB (1.048.576 bytes).

Gigabyte (GB)

Equivale a 1.024 MB (1.073.741.824 bytes). Estándar para medir la capacidad de memorias RAM, DVDs (4.7 GB) y aplicaciones.

Terabyte (TB) y Superiores

Terabyte (1.024 GB): Utilizado en discos duros modernos y servidores. Escalas mayores incluyen PB, EB, ZB y YB para grandes redes.

Jerarquía completa y equivalencias técnicas

Debido al sistema numérico binario de las computadoras, las unidades técnicas se agrupan en múltiplos de 1024 (también denominados con estándares binarios como Kibibyte, Mebibyte, etc.):

  • Kilobyte (KB): 1 KB = 1.024 bytes (10³ bytes en decimal). Ideal para documentos de texto y pequeños archivos.
  • Megabyte (MB): 1 MB = 1.024 KB (1.048.576 bytes). Usado para imágenes de alta resolución o canciones comprimidas.
  • Gigabyte (GB): 1 GB = 1.024 MB (1.073.741.824 bytes). Capacidad común en memorias y dispositivos multimedia.
  • Terabyte (TB): 1 TB = 1.024 GB (aprox. 1 billón de bytes / 2⁴⁰ bytes). Estándar actual en discos rígidos y almacenamiento masivo local.
  • Petabyte (PB): 1 PB = 1.024 TB. Utilizado para medir datos acumulados en granjas de servidores corporativos (como Google o Facebook).
  • Exabyte (EB): 1 EB = 1.024 PB. Mide el tráfico global de datos transferidos a través de Internet en períodos determinados.
  • Zettabyte (ZB): 1 ZB = 1.024 EB. Equivale a mil millones de Terabytes; dimensiona la totalidad de datos generados a nivel mundial.
  • Yottabyte (YB): 1 YB = 1.024 ZB (10²⁴ bytes en decimal o Yobibyte en binario 2⁸⁰). La unidad máxima oficial del Sistema Internacional de Unidades para datos. Nota: Los términos teóricos como Brontobyte o Saganbyte no son unidades reales.

Velocidades de transferencia de datos

Al transferir datos entre dispositivos o a través de redes, la velocidad se mide en bits por segundo (bps) o bytes por segundo (Bps):

  • 1 Byte por segundo (Bps) equivale a 8 bits por segundo (bps).
  • 1 Kilobyte por segundo (KBps) = 1.024 bytes por segundo.
  • 1 Megabyte por segundo (MBps) = 1.024 KBps.
  • 1 Gigabyte por segundo (GBps) = 1.024 MBps.
  • Dato récord: La velocidad de transferencia más rápida registrada alcanzó 1,84 petabits por segundo (Pbps).

Clasificación de las tecnologías de almacenamiento físico

Para retener físicamente los datos, las unidades emplean diferentes soportes:

Almacenamiento Magnético

Utilizan discos recubiertos de material ferromagnético y cabezales móviles. Ejemplo: Discos duros mecánicos (HDD).

Almacenamiento Flash (Estado Sólido)

Basados en semiconductores sin partes móviles; ofrecen alta velocidad y resistencia. Ejemplos: SSD, pendrives USB y tarjetas de memoria.

Almacenamiento Óptico

Guardan datos mediante surcos leídos por láser. Ejemplos: CD, DVD y Blu-ray.

Unidad 4: Modelo de Von Neumann y Arquitectura Interna

1. Estructura básica del Modelo de Von Neumann

Propuesto por John von Neumann en 1945, este modelo es la base de prácticamente todas las computadoras modernas. Su principio fundamental es el concepto de programa almacenado: tanto los datos como las instrucciones se guardan en la misma memoria principal y se tratan de forma similar.

Todo sistema informático bajo este modelo consta de tres componentes fundamentales interconectados a través de buses (de datos, direcciones y control):

Unidad Central de Proceso (CPU)

Es el cerebro del sistema. Se compone de la ALU (Unidad Aritmético-Lógica) que ejecuta cálculos, la UC (Unidad de Control) que dirige las operaciones y un conjunto de registros internos de alta velocidad.

Memoria Principal (RAM)

Almacén lineal y direccionable donde residen temporalmente tanto el programa en ejecución como los datos que utiliza. Es volátil y de acceso aleatorio.

Módulos de Entrada/Salida (E/S)

Interfaces que permiten la comunicación entre la CPU/Memoria y el mundo exterior (periféricos). Gestionan la transferencia de información.

2. El Ciclo de Instrucción (Fetch-Decode-Execute)

La CPU ejecuta los programas siguiendo un ciclo infinito y secuencial. Cada ciclo se divide en dos grandes fases:

Ciclo de Lectura (Fetch)

El procesador lee de a una las instrucciones desde la memoria principal. Utiliza un registro especializado llamado Contador de Programa (PC - Program Counter), el cual indica cuál es la próxima instrucción a ejecutar. Luego de leerla, el PC se incrementa de forma secuencial para apuntar a la siguiente.

Ciclo de Ejecución (Execute)

La instrucción leída se carga en el Registro de Instrucción (IR - Instruction Register) para ser decodificada e interpretada por la Unidad de Control. Las acciones resultantes se clasifican en cuatro categorías:

  • Transferencia Procesador-Memoria: Mover datos entre CPU y RAM.
  • Transferencia Procesador-E/S: Enviar/recibir datos de un periférico.
  • Tratamiento de datos: Operaciones aritméticas o lógicas mediante la ALU.
  • Control: Alteración de la secuencia de ejecución (saltos, bifurcaciones).
El cuello de botella de Von Neumann: Como la CPU y la memoria comparten el mismo bus, la velocidad de transferencia entre ambos limita el rendimiento general. Las memorias caché (L1, L2, L3) fueron creadas para mitigar este problema.

3. Diferencias Técnicas entre Procesadores de 32 y 64 bits

La diferencia no es solo "el doble de potencia", sino una cuestión de arquitectura, direccionamiento y compatibilidad.

Característica 32 bits (x86) 64 bits (x64)
Capacidad de procesamiento Maneja secuencias e información en bloques de hasta 32 bits por ciclo de reloj. Duplica la capacidad, permitiendo procesar bloques de datos mucho más grandes y complejos por ciclo, elevando el rendimiento.
Direccionamiento de RAM Limitación técnica de 2^32 direcciones = 4 GB de RAM máximo (aprovechando habitualmente ~3,25 GB efectivos). Direccionamiento teórico de 2^64. En la práctica, Windows 10/11 Pro admite hasta 192 GB o 2 TB según la edición.
Compatibilidad Solo puede ejecutar SO y aplicaciones de 32 bits. Puede ejecutar SO de 64 bits y, por compatibilidad, casi todo el software de 32 bits (mediante WOW64).

Unidad 5: El Sistema Operativo como Plataforma y Mediador

1. Definición y Objetivos

El Sistema Operativo (SO) es el conjunto de programas fundamentales que actúan como intermediarios entre el usuario, las aplicaciones y el hardware. Sin él, la computadora sería inutilizable para el usuario común.

Sus objetivos primordiales son tres:

Comodidad

Hacer que el uso de la computadora sea más sencillo, intuitivo y eficiente, ocultando la complejidad del hardware.

Eficiencia

Administrar los recursos del sistema (CPU, memoria, disco, periféricos) de manera óptima para maximizar el rendimiento.

Capacidad de evolución

Permitir el desarrollo de nuevas funciones, la actualización del sistema y la adaptación ante nuevas tecnologías y hardware.

2. Evolución Histórica Clave

El Sistema Operativo no existió desde el principio; evolucionó para resolver los problemas de cada época:

1. Procesos en Serie (Años 40-50)

Sin Sistema Operativo. El programador interactuaba directamente con la máquina mediante tableros de cableado y tarjetas perforadas. El tiempo ocioso de la CPU era elevadísimo porque había que cargar manualmente cada programa.

2. Sistemas por Lotes (Batch) y Multiprogramación (Años 60)

Aparece un software "monitor" residente que automatiza la carga de trabajos. Se introduce la técnica de interrupciones y el Acceso Directo a Memoria (DMA), que permite que los dispositivos de E/S operen en segundo plano. La CPU puede así ejecutar múltiples tareas intercaladas, reduciendo tiempos muertos.

3. Sistemas de Tiempo Compartido (Años 70 hasta la Actualidad)

Reparto dinámico del tiempo de procesamiento en ráfagas muy cortas llamadas cuantos o quantum. Esto da la ilusión de que múltiples usuarios utilizan la CPU simultáneamente. Es la base de los sistemas interactivos, multiusuario y multitarea como Windows, Linux y macOS.

Funciones principales de un SO moderno: Gestión de procesos, gestión de memoria RAM, gestión de archivos y almacenamiento secundario, gestión de dispositivos E/S, protección y seguridad, e interfaz de usuario (CLI o GUI).
